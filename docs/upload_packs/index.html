Every file each laboratory needs. Download the zip for the whole set, or take individual files from the list. These are plain files on an ordinary web server, so an assistant that can browse the web may be able to fetch them directly.

Laboratory 1 — inspecting a data series

Download all as one zip

  • 01a_inspect_dff.py — verify a data set before analysing it: types, coverage, missing values, provenance
  • 01b_monthly_transformations.py — selecting an observation versus calculating a statistic
  • 01c_state_cross_section.py — a cross section of the 50 states, and whether the dates actually line up
